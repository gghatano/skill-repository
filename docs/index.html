導入手順

Claude Code の /plugin でマーケットプレイスを追加し、目的のプラグインをインストールします。スキルは名前空間付き /<plugin>:<skill> で呼び出せます。

  1. 1

    マーケットプレイスを追加

    配布元として登録します（初回のみ）。

    /plugin marketplace add gghatano/skill-repository
  2. 2

    プラグインを導入

    必要なものだけ選べます。各カードからコピー可。

    /plugin install <name>@<marketplace>
  3. 3

    スキルを使う

    名前空間付きで呼び出します（例）。

    /research:report-review

プラグイン

目的ごとに、スキル本体・規約（docs）・サブエージェント（agents）を自己完結でまとめた配布単位です。

スキルと使い方

Claude Code では、会話がスキルの説明に一致すると自動で発火します。各カードは「話しかければ動く」内容を主役に、/<plugin>:<skill> のスラッシュコマンドは手動で呼ぶ場合の手段として併記しています。スキル名または「詳細 →」で、できること・使いどころ・入出力の詳細ページへ移動できます。
