Codex 画像生成ループ

codex-imagegen

Codex に画像を生成させ、Claude が目でレビューして再依頼するループ。

/codex-imagegen:codex-imagegen
SKILL.md を見る ↗

概要

Codex に画像（スライドの図・インフォグラフィック・図解の PNG）を 1 枚ずつ生成させ、出来上がった PNG を Claude が目でレビューして、具体的な指摘を付けて再依頼するループの回し方。生成そのものより 「出来上がった画像をどう見て、何をどう指摘し直すか」が本体。プロンプトの作り方・フォルダ構成・ 恒久ルール（AGENTS.md）・デザイン規約（STYLE.md）のテンプレートを同梱し、題材やデザインは差し替えて使う。 スライドの図・インフォグラフィック・図解の画像を作りたい／作り直したい、文言や文体を変えたい、 文字を大きくしたい、レイアウトの粗を直したい、Codex に画像を作らせて Claude Code に取り込みたい、 といった話が出たら使う。「Codex で画像」「インフォグラフィック」「スライドの図」「PNG を作り直して」 「プロンプトを直して」などの言い方でも、明示的に skill 名を呼ばれなくても使う。

できること

  • 作業ディレクトリをテンプレート（AGENTS.md / STYLE.md / gen.sh / make_prompts.py）から scaffold する
  • make_prompts.py にエッセンスと数値だけを書き、図解の実相は Codex に委ねる
  • gen.sh で Codex に PNG を 1 枚ずつ生成させ、バッチで回す
  • PNG を開いて改行崩れ・文字化け・重複・宙に浮いた線を見つける
  • 画面の文字列を引用し「それ以外は変えない」で締める指摘を書いて再依頼する
  • 2 枚以上で再発した粗を STYLE.md / AGENTS.md の恒久ルールへ昇格させる

使いどころ

Codex で画像（スライドの図・インフォグラフィック・図解の PNG）を作りたい／作り直したいとき、文言・文体・レイアウトの粗を直したいときに使う。生成そのものより「出来上がった画像をどう見て何を指摘し直すか」が本体。

入出力・連携

入力は題材（ラベル・ヘッドライン・素材・数値）と手本画像・配色/文字の規約、出力は 1920×1080 の PNG 群。scripts/（gen.sh・make_prompts.py）、templates/（AGENTS.md・STYLE.md・preview.html）、references/（review-checklist.md・feedback-patterns.md）を同梱する。

このスキルを導入

プラグイン codex-imagegen の一部です。

/plugin install codex-imagegen@gghatano-skills
