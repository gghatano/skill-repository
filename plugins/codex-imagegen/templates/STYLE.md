# デザインシステム（STYLE.md）

手本画像 `reference.png` と「同じ資料群に見える」ことを基準にします。

> このファイルはテンプレートです。**「色」と「タイポグラフィ」はプロジェクト固有**なので
> `＜…＞` を自分のブランド／手本画像に合わせて埋めてください。
> それ以外（日本語組版・文字化け対策・レイアウト作法・出力チェック）は領域非依存の
> 「見れば分かる粗」を防ぐルールなので、原則そのまま使えます。

## 色（プロジェクトごとに埋める）

| 用途 | 色 |
|---|---|
| キャンバス／カード | `＜#FFFFFF など＞` |
| カード罫 | `＜#RRGGBB＞` |
| 見出し | `＜#RRGGBB＞` |
| 本文 | `＜#RRGGBB＞` |
| 補助文 | `＜#RRGGBB＞` |
| 主色（線・文字・アイコン） | `＜#RRGGBB＞` |
| 主色の淡色 | `＜#RRGGBB＞` |
| 強調色 | `＜#RRGGBB＞` |

**強調色は各画像の最重要点 1 箇所だけ**に使います。濃色の大面積塗りや白抜き巨大数字は作りません。

## タイポグラフィ

- 書体は ＜`Noto Sans JP`, `Yu Gothic`, sans-serif など＞。
- キッカーは小さく、主色、字間を広めに。
- ヘッドラインを画面内で最大にします。
- カード見出しは主色、本文はチャコール、注記はグレーです。
- 数値は `tabular-nums` を使い、ライト地に濃色で置きます。

### 文字サイズの下限（1920×1080 の実寸。これより小さくしない）

| 役割 | サイズ |
|---|---|
| キッカー | 26px |
| ヘッドライン | 52〜60px |
| カード見出し | 34〜40px |
| 本文 | **28px 以上** |
| 注記・補助 | **24px 以上** |
| 主役の数値 | 96〜140px |
| 図中の小ラベル | **24px 以上** |

**入らないときに文字を小さくしてはいけません。要素を減らすか、文を短くします。**
1 枚に載せる項目数を削るほうが、縮めるより常に良い結果になります。

## 日本語の組版

日本語は語の間に空白がないため、放っておくと助詞や 1 文字だけの行ができます。これを禁じます。

- **文節で折ります。** 助詞・句読点・1 文字だけの行を作りません
  （「全チー／ムに公／開」「検出できま／した」のような折り方は不可）。
- 折り返しをブラウザ任せにしません。**文節ごとに `display:inline-block` の要素で包む**か、
  **自分で `<br>` を入れて**折り位置を決めます。`line-break: strict` を併用します。
- `word-break: break-all` は使いません（日本語を任意の位置で割ります）。
- **カード内の文は 2 行まで。** 3 行を超えるなら文を削ります。
- 数値と単位（`24 人`、`0.90`、`8月9日`）は途中で折りません。
- **文節を要素で包むときに、要素間の空白を出さないこと。**
  HTML の改行やインデントがそのまま空白になり、文の途中へ不自然な空白が入ります。
  タグを詰めて書くか、親を `font-size:0` にして子で戻します。

## 文字化けを出さない

- **絵文字・装飾記号・アイコンフォント・私用領域の文字を使いません。**
  `□`（豆腐）が出るのは、フォントに無い文字を使った証拠です。
- 図形・アイコンはすべて SVG のパスか、罫線・角丸ボックスで描きます。
- 書き出したら、画像内に `□` や欠け文字が無いことを必ず確認します。

## レイアウトと図解

- 1920×1080、16:9、ライト地。外周余白は左右 82px、上 62px を基準にします。
- ヘッダーは「キッカー → ヘッドライン → 細い罫」の順です。
- カードは角丸 20〜22px、罫 2px。カード内は上下左右 26〜38px の余白を確保します。
- **カードの高さは中身に合わせます。** 見出しだけを置いて下半分が空洞のカードを作りません。
  高さを揃えるために空白で埋めるのではなく、カードのほうを小さくします。
- **文字や枠を要素からはみ出させません。** 枠は中身に合わせて広げます（クリッピング禁止）。
- 各カードに、意味に合う細いラインアイコンを 1 つ添えます。
- 比較は同寸のカードを対等に並べます。集約は各入力から線を出し、合流点を経て結果へ接続します。
- 補助ケースは主図より小さくし、下段に分離します。
- 矢印・線・合流点は意味のある関係だけを示し、装飾には使いません。

### 軸のある図

散布・分布・時間経過・階段など、**位置が意味を持つ図には必ず軸名を置きます。**
読み手は「縦が何で横が何か」が分からないと図を読めません。

- 横軸・縦軸それぞれに**名前**を、軸のすぐ脇（離さない）に置きます。単位があれば添えます。
- 軸名は**縦書き（90 度回転）にしない**。横書きのまま軸の端の脇に置きます。
- 目盛りが要る図では、両端の値を示します。
- 軸名を置けない図は、そもそも軸で表すべきではありません。カードの並びに変えます。

### 情報量

余白は「軽く抜けた作り」のために取るもので、**中身が無いことの言い訳ではありません。**

- **1 カードにつき要点 3〜4 項目**を目安にします。1〜2 項目しかないカードは、
  他のカードと統合するか、素材を分割して増やします。
- **1 項目は 1 行に収まる長さ**にします。長い文を減らすのであって、項目数を減らすのではありません。
- 見出しだけで本文の無いカードを作りません。

### 線と矢印の作法

- **1 つの関係につき線は 1 本。** 同じ経路に矢印を二重に描きません。
- **端点はカードの縁に必ず接続します。** 宙に浮いた線、行き先のない線、
  長さ数十 px の意味のない罫線を置きません。
- **線を他のカードの上に通しません。** 交差しそうなら配置のほうを変えます。
- **並列の列挙に矢印を使いません。** 矢印は順序・因果・流れがあるときだけです。

### 同じ文言を二度出さない

- **図に符号化した内容を、注記としてもう一度書きません。**
- **プロンプトの「最重要メッセージ」を図の中にそのまま貼りません。**
  それはヘッドラインと図が伝えるべき内容です。図で言えているなら、文は置きません。
- カードの見出しと本文で同じことを言いません。

## 出力チェック

書き出した PNG を**必ず開いて**、次を 1 つずつ確認します。1 つでも欠けたら直して作り直します。

1. PNG 1 枚、1920×1080、ライト地。
2. 日本語ラベルと数値が指定どおりで、欠け・クリッピングがない。
3. **`□`（豆腐）や欠け文字が 1 つも無い。**
4. **助詞や 1 文字だけの行が無い。** カード内の文が 3 行を超えていない。
5. **本文が 28px 以上、注記が 24px 以上**に見える（1920px 幅での実寸）。
6. **同じ文言が 2 箇所に出ていない。**
7. **宙に浮いた線・二重の矢印・カードを横切る線が無い。**
8. 強調色が 1 箇所だけ、全カードにラインアイコンがある、カード内の余白が均等。
9. `reference.png` と並べ、重い塗り・多色・詰め込み・巨大数字になっていない。
