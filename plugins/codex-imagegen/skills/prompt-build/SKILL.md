# prompt-build — 骨子を生成用プロンプトへ変換する

`outline.md` の骨子 1 エントリを、`prompts/<stem>.md` 1 ファイルへ変換する。
フォーマットは同梱の `prompt.md` にある。**大事なのはこの構造**であって、変換の手段は問わない
（Claude が骨子を読んで書く／スライドが多ければ骨子を機械可読にしてスクリプトで書き出す、どちらでもよい）。
`.py` などの特定の実装に固定する必要はない。

```
outline.md（骨子・正本）  ──prompt-build──▶  prompts/<stem>.md（生成用・生成物）
```

## 変換で添える「固定部」

骨子には書かない、毎回ほぼ同じ部分。`prompt.md` の上半分に対応する。

1. **生成ルールの参照** — 「AGENTS.md に従う」「文章をカードに並べず 1 枚の図解にする」
   「数字・日本語ラベルを一字も変えない」。
2. **文体** — `outline.md` の house-style をそのまま差し込む。
3. **組版** — STYLE.md の下限、日本語の折り方、絵文字禁止、重複禁止、線の作法。
4. **出力仕様** — `out/<stem>.png`、16:9・幅 1920px・ライト地。

## 変換で差し込む「骨子部」

骨子ごとに変わる部分。`prompt.md` の下半分に対応する。

`label` → ラベル、`headline` → ヘッドライン、`key` → 最重要メッセージ、`audience` → 想定読者、
`structure` → 希望する構造、`emphasis` → 強調、`material` → 素材（`### 見出し` + `- 要点`）、
`facts` → 「必ず正確に載せる数値」（無ければ節ごと省く）。

## 手順

1. `outline.md` を読み、デッキ設定（audience / house-style）と各スライドの骨子を取り出す。
2. スライドごとに `prompt.md` の構造で `prompts/<stem>.md` を書き出す。
   - 固定部は house-style だけ差し替え、あとはそのまま。
   - 骨子部は各フィールドを対応する節へ。**素材の短句をそのまま**入れ、要約や創作をしない。
3. 出来た `prompts/*.md` を軽く確認する。
   - `facts` の数値が本文の素材と食い違っていないか。
   - `headline` が体言止めでなく**完全な文**になっているか。
   - 素材に専門用語が生のまま残っていないか（house-style の言い換えに直す）。

## 大事なこと

- **`prompts/*.md` は生成物。** 文言を変えるときは `outline.md`（正本）を直して変換し直す。
  `prompts/*.md` を手で直すと、次の変換で上書きされて迷子になる。
- **フォーマットを崩さない。** 節の見出し（`## ヘッドライン` 等）は Codex への構造化された指示なので、
  順序・見出しを保つ。中身だけ差し替える。
- **1 骨子 = 1 ファイル = 1 画像。** 複数スライドを 1 ファイルに混ぜない。

## 次へ
