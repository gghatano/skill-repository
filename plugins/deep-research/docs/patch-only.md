# Patch-only Rule

確定した草稿を、修正のたびに作り直さないための規約。

- 初稿確定後は全文再生成を行わない。`draft-01.md` を `Write` で上書きしない。
- 修正は Finding 単位の局所 Patch として行い、対象箇所・問題・根拠・修正内容・影響範囲を記録する。
- Patch 対象外の箇所を変更しない。引用番号・見出し・他の正しい主張を維持する。
- 規模上限（プロファイルの `max_lines_per_patch` / `max_total_changed_ratio`）を超える修正は、
  自動適用せず、構造問題として上位オーケストレーターへエスカレーションする。

## 判定

Lint `patch-scope`（Phase 2 以降）が対応する。
