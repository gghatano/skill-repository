# Canonical Query Rule

調査の正本入力を、実行中に変質させないための規約。

- ユーザーの原依頼を実行開始時に `query.md` として保存する。文字を落とさず、要約しない。
- 要約や言い換えを正本として使用しない。会話履歴の要約は正本ではない。
- すべての Skill は、作業開始時に `query.md` を再読する。前工程の要約で代替しない。
- 実行条件（保存先・出力形式・引用方式・禁止事項・期限・調査範囲）は
  `execution-contract.json` へ分離する。問いと条件を混在させない。
- 調査範囲を変更する場合は、`execution-contract.json` の `amendments` に
  「いつ・誰が・何を・なぜ」を追記する。`query.md` は書き換えない。

## 判定

`query.md` が存在せず、または実行途中で変更されている場合、Lint `query-preserved` が失敗する。
