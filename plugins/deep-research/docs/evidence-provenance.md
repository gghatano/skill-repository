# Evidence Provenance Rule

主張と根拠の対応を追跡可能に保つための規約。

- 主要主張は、情報源または「明示された推論」のいずれかに接続する。無接続の断定を残さない。
- 引用には情報源位置（節・ページ・見出し等）を保持する。URL だけを根拠としない。
- 数値には単位・期間・対象（母集団）を保持する。単位のない数値を本文に置かない。
- 情報源から導いた推論を、情報源自身の主張として表現しない。
  推論は「〜と考えられる」等ではなく、推論であることを構造上（`claim_type: inference`）記録する。
- 取得できなかった情報を、取得できたかのように書かない。未確認は未確認として残す。

## 判定

Lint `claim-provenance`（Phase 2 以降）と `quote-integrity` が対応する。
